# 使用 tmux 后台会话

本文操作对应当前 **macOS 客户端**。Android 的管理列表与 attach 尚未接入，列在[Android 实现计划](../reference/android-implementation.md) A8；共享 Core 已有接口不等于各端 UI 已交付。

普通本地 shell、SSH 和文件面板照常使用，不需要安装 tmux。
后台会话需要目标机器上的 **tmux 3.2a 或更新版本**；已验证 macOS 本机及 Ubuntu 22.04 SSH 目标的 3.2a 和 3.6a。

程序下拉框按目标登录环境的 PATH 顺序列出可执行文件及版本，默认使用第一个；不会自动跳过不支持的版本。可选择其他候选，或展开手动路径输入绝对路径，选择会按目标保存。远端非交互登录的 PATH 可能与交互终端不同（例如 mise 未加载时），此时可手动指定实际路径；PATH 探测失败也可以使用手动路径。
tmux 3.2a 连接刚建立时会初始化终端并清空已有输入；请等终端画面出现后再输入。
远端通过原有 libssh2、known_hosts 与凭据界面认证，需要 POSIX 兼容登录 shell、exec 和 PTY 权限。

## 打开和连接

点顶部右端或侧栏列表末尾唯一的 `+`，在“新建连接”选择本机/主机，把“打开为”切为“后台会话”，再点“打开”。已有终端标签的右键菜单也保留后台会话入口；侧栏现在只列活动标签，不列主机。只有打开或刷新列表时才探测目标，启动应用不探测。

默认查用户现有 tmux 实例。GUI 找不到程序时，在“可执行路径与 socket”里填绝对路径；
自定义 socket 也在这里指定。修改后必须刷新并重新选择，旧选择不能操作另一个 endpoint。

列表显示名称、窗口数和已连接客户端数。可新建、改名或结束所选 session；新建后选择
回读的实际名称，再点“在新标签页连接”。结束操作会确认目标，并影响其中的程序和客户端。
查询失败不会被显示成空列表；操作结果未知时先手动刷新，不自动重发。

连接总在新标签页的格子里打开，当前任务保持运行。每格是一个普通 tmux 客户端，
内部 window、pane、鼠标和前缀键由 tmux 自己处理。多个客户端可能共享窗口选择、输入与尺寸。
格子标注“连接时选择”，在 tmux 内切 session 后不会假装追踪当前目标；管理操作只从新列表选择。

调整窗口或窗格大小会更新终端尺寸，正常情况下不需要额外敲键触发重排。普通本地终端中手动执行系统 `ssh` 再进入远端 tmux 的路径，也已补齐 SIGWINCH 通知；如果旧版本存在“窗口变了、tmux 尺寸没变”，对应修复为 `4924a2d`。具体本机与远端测试范围见[实施清单](../reference/optional-tmux-implementation.md#后续-pty-尺寸通知修复2026-10-30)。

## 断开和重新选择

关闭格子、标签页或退出应用，只关闭 attach 客户端。tmux 前缀键 detach 或 SSH 断线后，
格子保留“连接已断开、后端状态未知”的提示。点“重新选择会话”会重新认证并取得新列表；
选中当前 session 后才在原格子连接，取消不改变原格子。不按旧名称或 ID 自动恢复，不重放输入。

连接前会显示 `destroy-unattached` 和 `exit-unattached` 的保留策略。开启这些选项、用户 hooks、
系统登出清理或机器重启都可能结束后台任务；Ghosterm 不修改配置，也不承诺跨重启保活。
历史和画面由 tmux 提供，SFTP 传输不因此保活。

实现边界与当前证据见[能力矩阵](../reference/capability-matrix.md)和[实施清单](../reference/optional-tmux-implementation.md)。
