TERMINAL / SESSION SWITCHER

会话，一点就能找到。

底部保留一个固定入口。展开后按主机找到终端，切换后继续输入。

可点击原型 · 全部为演示数据
01

随时可见的入口

试着点击右下角

入口固定在辅助键右侧。辅助键横向滚动或隐藏时，会话按钮与更多菜单都保持可见。

02

展开后的会话面板

点击一行即可切换

切换后收起面板，继续当前输入节奏。右侧关闭按钮仅收起面板；每行的更多按钮操作该行会话。

面板布局

A / 快速返回

两台终端，来回切

“返回上一会话”放在列表上方。列表保持主机分组与稳定顺序，切换后不用重新找位置。

B / 看清目标

同一主机，也能区分

主机名做分组，同主机终端加编号。当前项用底色、侧线与文字共同标记，SSH、tmux 和本地类型明确显示。

C / 新建与整理

常用操作留在底部

新建入口固定可见。已停止会话默认折叠，展开可查看旧画面；关闭会话先确认。多会话场景增加搜索。

终端菜单移除“切换会话”。
