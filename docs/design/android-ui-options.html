01 / 拇指可达

主操作靠近底部；应用按钮命中区域至少 48 CSS px（对应设计中的 48 dp）。长按和侧滑只作快捷方式，始终保留可见入口。

02 / 给输入让位

打开键盘即收起主导航，辅助键贴住键盘。终端内部不安排横向切页手势，避免抢走命令行程序的触摸操作。

03 / 文件为单栏

手机用「远端 / 本机」切换代替双栏；点按进目录，选择框进入多选，传输前明确源、目的地和冲突处理。

04 / 返回有层次

先关闭底部面板，再收键盘，再返回上一页。关闭连接单独确认；普通 SSH 默认，后台会话显式选择 tmux。

原型范围：离线单文件 HTML，所有主机、状态和输出均为演示数据，不执行命令、不保存凭据、不发起网络请求。软键盘为布局示意（字母键由系统键盘负责）；辅助键与页面按钮可操作。Android 原生端尚未实现，本文件不代表能力验收。大屏导航栏、真机 IME / TalkBack / 系统返回与横屏仍需在原生阶段验证。
