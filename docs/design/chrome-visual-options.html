少画几条线，让终端回到视线中心。

你的感觉有依据：侧栏、顶栏和窗格标题的底色来源不一致，分隔线、卡片边框与焦点描边又叠在一起。下面三案使用同一组内容与布局，只比较底色、边界和焦点提示。

01 / 导航应该像同一套界面

侧栏及其红绿灯区域、顶部标签栏共用一套导航底色。窗格标题属于内容层，可跟随终端背景，不必所有区域都刷成一个颜色。

02 / 一个边界，不必反复描绘

当前同时存在侧栏分隔线、窗格整圈边框、标题底线和分屏间隙。优先用间距区分窗格，再决定哪里确实需要线条。

03 / 焦点只用一处强调

收掉整圈亮蓝描边与整块蓝色标题底，保留小焦点标记、清晰标题与适度的非聚焦变暗。连接状态点继续表示连接状态。

A：中性的导航外壳，终端内部不画整圈边框；窗格标题沿用终端底色，当前窗格只在标题前保留一条短色线。
