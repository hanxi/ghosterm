# macOS 文件导航、历史与树读取

2026-11-17，本片只接 `FilesPanelModel` / `FilesPanelView` 的读取状态，不改变 FileBackend 协议、SFTP owner、传输提交或 Core ABI。

导航捕获已成功发布的目录/历史快照，回包按请求身份核对；旧成功和旧失败不能覆盖新请求的路径、条目、错误或 loading。已经排队而被取代的读取不启动。前进/后退只在成功后提交历史，失败保留原位置、条目、选择和可重试目标。导航退出旧搜索视图；后端搜索取消另批推进。跟随 cwd 不重复取消同一个仍在读取的目录，避免慢读取被每秒轮询饿死。

刷新清理树缓存/错误/加载状态并推进 epoch，重新查询当前根和仍展开的分支；旧回包不能重填缓存或清除新读取的 loading。换根成功后清理旧展开状态。目录读取失败不写空缓存，显示路径相关错误并可重试；只有成功读到空集合才显示无子目录。

根和子目录读取状态放在目录树之外、最高 132 pt 的滚动状态区，重试操作按原路径路由。前置原生测试发现放在虚拟 outline 行的错误/按钮未暴露 AX 控件，不能记绿；移出虚拟行后，真实根/子目录错误与两次按钮重试通过。离屏透明窗口只证明进程内 AppKit/SwiftUI 控件与 AX，不代替系统 VoiceOver/真实桌面操作。
